## 5-2. 가격 스냅샷과 가격 이력 참조

**무엇을 정하나요?**
주문 상품 행에 **어떤 가격 값을 복사하고, 상품 쪽 가격 이력 중 어느 행에서 나온 값인지 남길지**입니다. 쿠폰 같은 할인은 6분야에서 다루고, 여기서는 할인 전의 상품 가격만 다룹니다.

**상품 쪽 가격 구조 (상품 도메인에서 확정)**
- **정가:** 처음 매긴 가격 (예: 69,000원)
- **판매가:** 실제로 파는 가격. 가격 이력(`PRD_PRICE_HIST`)의 행 하나가 "이 기간에 이 가격"을 뜻합니다. 스타일 전체에 걸리는 행과 특정 컬러에만 걸리는 행(컬러 특가)이 있습니다.
- **SKU 추가 금액:** 큰 사이즈 등 SKU에 따라 더 받는 금액

상품 결정 PC-33에서 "주문 상품에 그때 적용된 가격 이력 행 ID를 남기는 것은 주문 도메인에서 정한다"고 넘겨 두었습니다.

**예시로 보면**
- 셔츠 정가 69,000원
- 스타일 전체 판매가 59,000원
- 블랙 컬러만 특가 49,000원
- XL은 SKU 추가 금액 2,000원

고객이 블랙 XL을 샀다면 주문 단가는 49,000 + 2,000 = 51,000원입니다. 나중에 "왜 51,000원이었나요?"라고 물으면 "블랙 특가 행(이력 ID 1234) + XL 추가 금액"이라고 답할 수 있어야 합니다.

**왜 정가도 남기나요?**
주문 화면과 서면에 "69,000원 → 51,000원 (26% 할인)"처럼 보여 줍니다. 표시·광고법은 할인 전 가격을 사실과 다르게 표시하는 것을 금지합니다 (부당한 표시·광고 고시). 그때 정가를 남겨 두면 표시가 사실이었다는 근거가 됩니다.

**선택지**

| 선택지 | 방식 | 장점 | 단점 |
|---|---|---|---|
| A | 주문 단가(51,000원) 하나만 복사함 | 컬럼이 하나 | 할인 표시의 근거(정가)와 가격의 구성(판매가 + 추가 금액)을 설명할 수 없음 |
| B | 정가, 판매가, SKU 추가 금액 세 값을 복사함 | 화면 표시와 가격 구성을 모두 설명함 | 어느 가격 행(스타일 전체 / 컬러 특가)에서 나온 값인지 알 수 없음 |
| **C** | B에 더해 그때 적용된 가격 이력 행 ID를 남김 | 가격의 출처까지 정확히 추적함. PC-33에서 넘어온 과제를 해결함 | 가격 이력 행을 주문 보관 기간 동안 지우면 안 됨 |

**추천: C.**
- 가격 이력은 이미 "삭제하지 않고 반대 행으로 정정하는" 이력 테이블입니다 (선행 4). 그래서 주문이 가리키는 행이 사라질 걱정이 없습니다. 이 점이 5-1의 표시 내용 이력과 다릅니다.
- 값 세 개는 복사하고 이력 ID도 남깁니다. 이력 ID만 남기면 값을 볼 때마다 조인해야 하고, 값만 남기면 출처를 모릅니다.
- CHECK로 판매가 ≤ 정가, 단가 = 판매가 + SKU 추가 금액을 겁니다.

**C를 고르면 주문 상품 테이블에 생기는 것**
- 정가, 판매가, SKU 추가 금액, 주문 단가 (`_AMT`, `NUMBER(15)`)
- 적용 가격 이력 ID (FK → `PRD_PRICE_HIST`)
- CHECK 2개

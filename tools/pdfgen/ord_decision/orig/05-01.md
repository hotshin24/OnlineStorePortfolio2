## 5-1. 상품 스냅샷 범위

**무엇을 정하나요?**
주문 상품 행에 **상품 정보를 얼마나 복사해 둘지**입니다. 가격은 5-2, 이미지는 5-3, 청약철회 제한 문구는 5-9에서 따로 정하고, 여기서는 그 밖의 상품 정보를 다룹니다.

**예시로 보면**
1. 1월에 "오버핏 코튼 셔츠 블랙 M"을 샀습니다.
2. 3월에 상품명이 "릴렉스 핏 코튼 셔츠"로 바뀌고, 컬러명 "블랙"이 "차콜 블랙"으로 바뀝니다.
3. 6월에 고객이 주문 내역을 열어 봅니다.

고객이 본 것은 1월의 이름입니다. 주문 내역도, CS 기록도, 분쟁 때 증빙도 1월 이름이어야 합니다.

**선택지**

| 선택지 | 방식 | 장점 | 단점 |
|---|---|---|---|
| **A** | 자주 쓰는 값만 컬럼으로 복사함. 상세 설명과 상품정보 고시는 상품 쪽 표시 내용 이력(`PRD_DISPLAY_CONTENT_HIST`)의 그때 버전 ID로 가리킴 | 목록·검색·정산·리뷰에 쓰는 값은 조인 없이 바로 씀. 긴 상세 설명은 복사하지 않아 가벼움 | 표시 내용 이력 행을 주문 보관 기간 동안 지우면 안 됨 (상품 쪽 이력 보관 규칙과 묶임) |
| B | 주문 때 상품 정보 전체를 JSON 하나로 통째 저장함 | 무엇이든 남음. 상품 쪽 이력에 의존하지 않음 | 주문 상품마다 큰 JSON이 쌓임. 컬럼이 아니라 목록·통계에 쓰기 어려움 |
| C | 복사하지 않고 SKU FK만 둠. 필요할 때 상품 쪽 이력에서 그때 값을 찾음 | 중복이 없음 | 예시의 이름 변경을 이력에서 시점으로 찾아야 해 조회가 무거움. 이름 변경 이력이 없는 값은 찾을 수 없음 |

**추천: A.**

**A로 복사할 값 (후보)**
- 스타일 코드(품번), 상품명, 브랜드명
- 컬러 코드·컬러명, 사이즈명
- SKU 코드
- 과세 구분 (6-7 과세·면세 금액 분리에 씀)
- 표시 내용 이력 버전 ID

**표시 내용 이력 버전 ID를 FK로 걸 때**
- FK를 걸면 그 이력 행은 주문이 남아 있는 동안 지울 수 없습니다.
- 표시·광고 기록의 법정 보관은 6개월입니다 (시행령 6조). 상품 쪽에서 이력을 짧게 정리할 계획이 있다면, 주문에서 가리키는 버전은 남기도록 상품 쪽과 맞춰야 합니다.
- 이것은 [확인 필요]로 남겨 결정 단계에서 FK로 할지, 참조 값(FK 없음)으로 할지 함께 고르시도록 하겠습니다.

**A를 고르면 주문 상품 테이블에 생기는 것**
- 위 복사 값 약 9개
- SKU ID FK (4-2)

## 4-2. 주문 상품 행 단위

**무엇을 정하나요?**
주문 상품 테이블의 **행 하나가 무엇을 뜻하는지**입니다. 장바구니의 2-1과 같은 질문을 주문에 대해 하는 것입니다.

**예시로 보면**
고객이 같은 양말(같은 SKU)을 3켤레 샀습니다.
- **SKU당 1행:** "양말 × 3" 한 줄
- **수량 1개당 1행:** "양말 × 1" 세 줄

**이 선택이 영향을 주는 곳**
- **취소·반품:** 3켤레 중 1켤레만 반품하는 경우
- **리뷰:** 주문 상품 1건당 리뷰 1개입니다 (선행 17, `ORDER_ITEM_ID` UK). 행 단위가 곧 리뷰 단위가 됩니다.
- **1-6 A:** 이미 "주문 상품에 취소 수량·반품 수량 컬럼을 둔다"를 골랐습니다. 이것은 SKU당 1행을 전제로 합니다.

**선택지**

| 선택지 | 방식 | 장점 | 단점 |
|---|---|---|---|
| **A** | SKU당 1행 + 주문 수량. 취소·반품은 수량 컬럼으로 셈 (1-6 A) | 행 수가 적음. 장바구니 행 단위(2-1 A)와 같아 주문으로 옮기기 쉬움. 리뷰는 같은 상품에 하나만 씀 | 3켤레 중 1켤레만 다른 처리(교환 등)를 할 때 행 하나 안에서 수량으로 나눠 표현해야 함 |
| B | 수량 1개당 1행 (같은 SKU 3개면 3행) | 낱개마다 상태가 따로 있어 부분 처리가 단순함 | 같은 양말에 리뷰를 3개 쓸 수 있게 됨. 행 수가 늘고 금액 배분(6-4)도 행마다 나눠야 함. 1-6 A와 맞지 않음 |
| C | A로 저장하되, 클레임 도메인이 클레임 상품 행에서 수량 단위로 나눠 처리함 | 주문은 A처럼 단순하고, 부분 처리는 클레임에서 함 | 사실상 A와 같음 (A에서도 클레임은 수량 단위로 기록함) |

**추천: A.**
- 패션에서 같은 SKU를 여러 개 사는 경우는 양말·속옷 정도라 드뭅니다. 드문 경우를 위해 모든 주문을 낱개 행으로 쪼갤 이유가 없습니다.
- 부분 취소·반품은 클레임 도메인이 "이 주문 상품에서 몇 개"를 기록하고, 주문 상품에는 그 합계만 반영합니다 (1-6 A). 그래서 C는 A에 포함되는 내용이라 따로 고를 필요가 없습니다.
- 리뷰는 같은 상품에 하나가 자연스럽습니다. 같은 양말 3켤레에 리뷰가 3개 달리는 것은 리뷰 품질을 떨어뜨립니다.

**A를 고르면 주문 상품 테이블에 생기는 것**
- SKU ID (FK)
- 주문 수량: CHECK 1~99로 장바구니(2-5)와 같은 범위
- 취소 수량, 반품 수량 (1-6 A)
- CHECK: 취소 수량 + 반품 수량 ≤ 주문 수량
- 같은 주문 안에서 같은 SKU는 1행만 두는 UK(주문 ID, SKU ID)

**사용자:** a

4-2는 A로 메모했습니다.

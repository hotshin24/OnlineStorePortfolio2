## 3-1. 결제 상태 값

**무엇을 정하나요?**
결제 행이 가질 상태 값의 목록과, 취소 상태를 승인 흐름과 같은 컬럼에 둘지 따로 둘지 정합니다. 상태는 로직이 걸린 코드라 CHECK도 겁니다(규칙 4).

**이미 정한 것**
- 2-1 A: 결제 행은 "준비"로 시작합니다. 주문이 만료되면 준비·인증 완료 상태 행도 "만료"가 됩니다.
- 2-2 C: "주문 결제이면서 승인·부분 취소 상태인 행"에 주문당 UK를 겁니다.
- 2-7 A: 취소 누계 금액이 있고, 잔액은 가상 컬럼입니다.
- 주문 3-4 A: 가상계좌는 입금 기한까지 입금을 기다립니다.
- 다음 패턴들이 이 값을 씁니다: 3-7(결과 불명), 3-8(만료 뒤 승인), 4-x(가상계좌).

**예시로 보면**
1. **카드 정상:** 준비 → 인증 완료 → 승인
2. **결제창에서 취소:** 준비 → 실패. 실패 사유는 "사용자 취소"입니다.
3. **한도 초과:** 준비 → 인증 완료 → 실패. 실패 사유는 "한도 초과"입니다.
4. **응답 없음:** 준비 → 인증 완료 → 결과 불명 → (PG에 조회하니 승인돼 있음) → 승인
5. **가상계좌:** 준비 → 입금 대기 → 승인(입금 확인). 또는 입금 대기 → 만료
6. **반품:** 승인 상태에서 3만 원을 취소하면 "부분 취소", 나머지 6만 5천 원까지 취소하면 "전체 취소"가 됩니다.

**선택지**

| 선택지 | 방식 | 장점 | 단점 |
|---|---|---|---|
| A | 상태 컬럼 하나에 흐름 전체를 담습니다: 준비, 인증 완료, 입금 대기, 승인, 부분 취소, 전체 취소, 실패, 결과 불명, 만료 (9개) | 컬럼 하나만 보면 됩니다. 국내 PG 응답 상태와 비슷합니다. | 부분 취소·전체 취소는 2-7의 취소 누계로도 알 수 있어 같은 사실이 두 곳에 생깁니다. 상태를 "부분 취소"로 바꾸는 것을 잊으면 누계와 어긋납니다. |
| **B** | **승인 상태**(준비, 인증 완료, 입금 대기, 승인, 실패, 결과 불명, 만료: 7개)와 **취소 상태**를 나눕니다. 취소 상태는 금액에서 계산하는 가상 컬럼입니다: 누계 0이면 없음, 누계 < 승인 금액이면 부분, 누계 = 승인 금액이면 전체. | 취소 상태가 금액과 어긋날 수 없습니다(2-7 A와 같은 원리). 승인 상태는 승인에서 멈추므로 흐름이 단순합니다. 2-2 C의 UK 조건이 "주문 결제이면서 승인 상태"로 간단해집니다. | 화면에 "부분 취소"로 보이려면 두 값을 조합합니다. |
| C | 준비, 승인, 실패, 취소 4개만 두고, 결과 불명·입금 대기는 Y/N 컬럼으로 둡니다. | 값이 가장 적습니다. | 상태와 Y/N 컬럼의 조합이 맞지 않는 행이 생길 수 있습니다(예: 승인 + 입금 대기 Y). 3-7·4-x에서 CHECK가 복잡해집니다. |

**추천: B.**
- 승인 흐름(PG와 주고받는 결과)과 취소(그 뒤 금액 변동)는 성격이 다릅니다. 취소는 이미 금액 컬럼이 정확히 담고 있으므로 상태로 한 번 더 저장하지 않습니다.
- 2-2 C의 UK에서 전체 취소된 결제도 계속 "승인" 상태로 남습니다. 그래서 한 번 결제됐다가 전액 취소된 주문에 새 주문 결제가 승인되는 것도 DB가 막습니다. 주문 취소는 되돌리지 않으므로 이 동작이 맞습니다.

**B를 고르면 생기는 것 (이름은 후보)**
- 승인 상태 코드 `PAYMENT_STATUS_CD`:
  - 값: `READY`, `AUTHENTICATED`, `WAITING_DEPOSIT`, `APPROVED`, `FAILED`, `UNKNOWN`, `EXPIRED`
  - CHECK로 값 목록을 겁니다.
- 실패 사유 코드: 사용자 취소, 한도 초과, 잔액 부족, 인증 실패, 금액 불일치, PG 오류 등. PG 원래 코드와 메시지도 함께 저장합니다.
- 취소 상태 가상 컬럼 `CANCEL_STATUS_CD`: `NONE` / `PARTIAL` / `FULL`
- CHECK 두 가지:
  - 상태가 `APPROVED`면 승인 금액, 승인 일시, PG 거래번호가 NOT NULL입니다.
  - 상태가 `APPROVED`가 아니면 취소 누계는 0입니다.
- 상태가 바뀔 때마다 남기는 기록은 3-2에서 정합니다.

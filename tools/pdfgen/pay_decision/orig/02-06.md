## 2-6. 결제 행에 남기는 PG·MID 정보

**무엇을 정하나요?**
1-5 A에서 "결제 행에는 실제로 쓴 PG 코드와 MID를 남긴다"고 정했고, 1-7 C에서 정산 방식과 카드사 가맹점번호를 더했습니다. 이 패턴에서는 그 값을 **결제 행에 값으로 복사할지, 1-5의 PG 설정 행을 FK로 가리킬지** 정합니다.

**이미 정한 것**
- 1-5 A: 결제 수단 × PG 설정 테이블이 있습니다. 마스터·설정이라 논리 삭제하고, 1년 뒤 물리 삭제합니다(선행 4).
- 1-7 C: 결제 행에 정산 방식 코드와, 직정산일 때 카드사 가맹점번호를 결제 시점 값으로 복사합니다.
- 선행 13: PG 업체 코드는 외부 업체 마스터(`SYS`)의 업체 코드입니다. (PG 업체 코드 + PG 거래번호)에 UK를 겁니다(2-8).
- 선행 4: 자식이 있는 부모는 삭제할 수 없습니다.
- 회원 40-1 D: 원클릭 결제는 빌링키를 발급한 PG와 빌링용 MID로만 결제합니다.

**예시로 보면**
1. **평소 결제:** 카드 결제가 설정 행 #12(PG-가, MID `pgga_main01`, 우선순위 1)로 나갑니다.
2. **MID 교체:** 3월에 PG-가가 MID를 `pgga_main02`로 바꿔 발급합니다. 운영자가 설정 행 #12를 직접 고치거나, #12를 끝내고 새 행 #20을 만듭니다. 2월 결제는 여전히 `pgga_main01`로 취소해야 합니다.
3. **장애 분석:** 금요일 밤 2시간 동안 카드 결제가 PG-나로 나갔습니다. 나중에 "그때 어떤 설정이 적용됐나"를 확인합니다.
4. **설정 정리:** 2년 전에 해지한 PG-다의 설정 행을 물리 삭제하려 합니다. 그 행을 가리키는 결제가 수십만 건 있습니다.
5. **원클릭 결제:** 이 결제는 설정 테이블이 아니라 저장 결제수단을 발급한 PG로 나갑니다. 설정 행을 거치지 않습니다.

**선택지**

| 선택지 | 방식 | 장점 | 단점 |
|---|---|---|---|
| **A** | **값만 복사합니다.** 결제 행에 PG 업체 코드, MID, 정산 방식, 카드사 가맹점번호를 결제 시점 값으로 넣고, 설정 행 FK는 두지 않습니다. | 예시 2에서 설정을 어떻게 고쳐도 과거 결제의 취소 대상 MID가 그대로입니다. 예시 4처럼 설정을 지울 때 결제 행이 막지 않습니다. 예시 5(원클릭)도 같은 컬럼으로 표현합니다. | 예시 3은 결제 행의 PG 값과 설정의 적용 기간, 관리자 작업 로그를 대조해 알아냅니다. |
| B | **설정 행 FK만 둡니다.** PG와 MID는 조인해서 읽습니다. | 컬럼이 가장 적습니다. | 예시 2에서 설정 행을 직접 고치면 과거 결제의 MID가 바뀐 것처럼 보여 취소가 실패합니다. 예시 4의 삭제가 막힙니다. 예시 5는 FK가 NULL입니다. |
| C | **값을 복사하고 설정 행 FK도 둡니다.** | 예시 3에서 적용된 설정을 바로 압니다. 과거 값도 보존됩니다. | 예시 4의 물리 삭제가 막혀, 설정 행이 영구 보관으로 바뀝니다. 큰 결제 테이블에 FK 인덱스가 하나 더 생깁니다. |

**추천: A.**
- 취소·대사·정산에 필요한 것은 "그때 실제로 쓴 값"이고, 그 값은 복사본이 정확히 담습니다. 주문 도메인에서 가격을 스냅샷으로 남긴 방식(주문 5-2 C)과 같습니다.
- 예시 3(장애 분석)은 7-5(PG 장애와 전환 기록)에서 전환 기록을 남기기로 하면 충분히 답할 수 있습니다.

**A를 고르면 생기는 것 (이름은 후보)**
- 결제 행 컬럼:
  - PG 업체 코드 (외부 업체 마스터의 코드 값. FK로 걸지는 컬럼 검토 때 여쭙겠습니다)
  - MID
  - MID 용도(일반 / 빌링)
  - 정산 방식 코드
  - 카드사 가맹점번호
- CHECK 두 가지:
  - 수단이 `ONE_CLICK`이면 MID 용도는 빌링
  - 정산 방식이 `CARD_DIRECT`면 카드사 가맹점번호가 NOT NULL (1-7 C)
- 설정 테이블 설명에 "결제 행은 설정을 참조하지 않고 값을 복사한다. 설정 행을 고쳐도 과거 결제에는 영향이 없다"를 적습니다.

**사용자:** a

2-6은 A로 메모해 두었습니다. PG 업체 코드에 외부 업체 마스터 FK를 걸지는 컬럼 검토 때 여쭙겠습니다.

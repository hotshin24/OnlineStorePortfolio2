## 8-4. PG 원문의 가림 규칙과 보관

**무엇을 정하나요?**
7-1 C에서 PG 요청·응답 원문은 DB가 아니라 외부 로그 도구에 두기로 했습니다. 그 원문에서 무엇을 어떻게 가리고 나서 보낼지, 외부 도구의 접근과 보관을 어떻게 통제할지 정합니다.

**이미 정한 것**
- 7-1 C: DB에는 요약 행과 외부 로그 추적 ID만 있습니다. 원문은 외부 로그 도구에 있습니다.
- 7-2 A: 웹훅 수신함에는 원문 없이 식별 값만 둡니다. 웹훅 원문도 외부 로그 도구로 갑니다.
- 8-1 A: 카드번호 원문, 유효기간, CVC는 어디에도 두지 않습니다.
- 8-2 B: 빌링키는 결제 행과 로그 어디에도 남기지 않습니다.
- 8-3 B: 고객 계좌번호, 휴대폰 번호, 현금영수증 식별번호는 DB에서 암호문입니다.

**원문에 들어 있을 수 있는 민감값**
- PG 인증 키·서명 값(우리 비밀 키)
- 빌링키
- 카드번호 앞뒤 자리(마스킹 형태)
- 고객 계좌번호, 휴대폰 번호, 이름, 이메일
- 현금영수증 식별번호
- 결제창 인증 토큰

**예시로 보면**
1. **승인 응답:** PG 응답 JSON에 `billingKey`, `card.number`(마스킹), `customerMobilePhone`이 들어 있습니다.
2. **새 필드:** PG가 API를 개편하면서 응답에 `customerBirthDate` 필드를 새로 넣습니다. 우리는 공지를 못 봤습니다.
3. **분쟁 조사:** 상담 팀장이 6개월 전 결제의 원문을 열람합니다. 누가 언제 열람했는지 남아야 합니다.
4. **외부 도구가 클라우드 서비스:** 원문 안의 개인정보가 외부 업체 서버에 저장됩니다.

**선택지**

| 선택지 | 방식 | 장점 | 단점 |
|---|---|---|---|
| **A** | **허용 목록 방식으로 가립니다.**<br>• PG별·API별로 "그대로 남겨도 되는 필드" 목록을 두고, 목록에 없는 필드는 모두 가립니다(예시 2의 새 필드도 자동으로 가려짐).<br>• 인증 키, 서명, 빌링키, 인증 토큰은 목록과 상관없이 항상 지웁니다.<br>• 외부 도구는 열람 권한을 결제 운영자로 제한하고, 열람 기록을 남깁니다(예시 3).<br>• 보관 기간은 11-2에서 DB 요약 로그와 같게 정합니다. | 새 필드가 생겨도 새어 나가지 않습니다. 가린 원문은 분쟁 조사에 충분합니다(결과 코드, 금액, 시각, 마스킹 번호). | PG가 바뀌거나 API가 개편되면 허용 목록을 고쳐야 합니다. 목록을 늦게 고치면 필요한 필드까지 가려집니다. |
| B | 금지 목록 방식으로 가립니다. 알려진 민감 필드만 가리고 나머지는 그대로 둡니다. | 목록이 짧고 필요한 정보가 다 남습니다. | 예시 2처럼 새 민감 필드가 생기면 그대로 외부로 나갑니다. |
| C | 원문을 아예 남기지 않습니다. DB 요약만 둡니다. | 유출 위험이 없습니다. | 분쟁 조사 때 PG가 실제로 무엇을 돌려줬는지 볼 수 없습니다. 7-1 C에서 원문을 외부에 두기로 한 의미가 사라집니다. |

**추천: A.**
- 외부 도구로 나가는 데이터는 "알려진 안전한 것만 통과"가 기본입니다. 결제처럼 민감값이 많은 원문에서 금지 목록 방식은 PG 개편 한 번으로 뚫립니다.
- 가린 원문으로도 분쟁에 필요한 사실(결과, 금액, 시각)은 모두 남습니다.

**A를 고르면 생기는 것 (DB 쪽)**
- 허용 목록을 어디에 둘지 정해야 합니다. 후보는 두 가지이고, 컬럼 검토 때 여쭙겠습니다.
  - 애플리케이션 설정
  - DB 설정 테이블(PG × API × 필드 경로)
- 외부 도구 열람 기록:
  - 개인정보 접속 기록(선행 6의 용도별 감사 로그)에 남깁니다.
  - 외부 도구에서 기록하면 그 기록의 보관 기간(개인정보 안전성 확보조치 기준 8조, 최소 1년, 조건에 따라 2년)을 맞춥니다.
- [확인 필요: 법무] 외부 로그 도구가 클라우드 서비스이면 개인정보 처리 위탁에 해당하는지, 처리방침에 공개해야 하는지(개인정보 보호법 26조)

<!--ANSWER-->
**사용자:** a

8-4는 A로 메모해 두었습니다. PG 원문은 허용 목록 방식으로 가린 뒤 외부 로그 도구로 보냅니다. 인증 키, 빌링키, 인증 토큰은 항상 지웁니다. 외부 도구는 열람 권한을 결제 운영자로 제한하고, 열람 기록을 남깁니다.

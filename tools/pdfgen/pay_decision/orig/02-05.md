## 2-5. 간편결제 구분

**무엇을 정하나요?**
간편결제는 "어느 회사의 간편결제인가"(카카오페이, 네이버페이 등)와 "그 안에서 무엇으로 냈나"(카드, 충전 머니, 포인트, 계좌)가 겹쳐 있습니다. 이 두 가지를 어떤 컬럼으로 나눠 담을지 정합니다. 내부 수단에 따라 환불 경로, 현금영수증 발급 여부, 여신전문금융업법 적용(카드)이 달라집니다.

**이미 정한 것**
- 선행 13: 간편결제는 직접 계약입니다. 1-5 A의 PG 설정에서 간편결제사도 하나의 "PG 업체 코드"로 다룹니다.
- 1-4 A: 결제 수단 코드에 `EASY_PAY`와 자사 원클릭 `ONE_CLICK`이 따로 있습니다.
- 2-4 A: 결제 테이블에 카드 그룹 컬럼이 있고, 간편결제의 내부 카드 정보도 그 컬럼에 담습니다.
- 2-2 C: 주문당 승인된 PG 결제는 1건입니다.

**예시로 보면**
1. **카카오페이 + 카드:** 카카오페이에 등록한 현대카드로 3개월 할부 결제를 합니다. 환불은 현대카드 승인 취소로 처리합니다.
2. **카카오페이 + 머니:** 카카오페이머니로 결제합니다. 환불은 카카오페이머니로 돌아갑니다. 현금성 결제라 현금영수증 대상입니다 [확인 필요: 세무, 발급 주체].
3. **네이버페이 안에서 나눠 낸 경우:** 9만 5천 원을 네이버페이 포인트 5천 원과 신한카드 9만 원으로 냅니다.
   - 우리 쪽에서는 승인 1건(2-2 C를 지킴)이지만, 간편결제사 안에서 금액이 둘로 나뉩니다.
   - 부분 반품을 하면 간편결제사가 어느 쪽부터 돌려줄지 정합니다.
4. **삼성페이·애플페이:** 카드를 토큰화한 결제라 PG가 "카드 결제"로 돌려주는 경우가 많습니다. 어느 수단 코드로 볼지 정해야 합니다.
5. **통계:** "이번 달 카드 결제 총액"을 구할 때, 일반 카드 결제와 간편결제 안의 카드 결제를 합쳐야 하는지 따로 봐야 하는지 정해야 합니다.

**선택지**

| 선택지 | 방식 | 장점 | 단점 |
|---|---|---|---|
| **A** | 결제 수단은 `EASY_PAY` 하나로 두고, **간편결제사 코드**와 **내부 결제 수단 코드**(카드 / 머니 / 포인트 / 계좌 / 혼합) 컬럼을 둡니다. 내부가 카드면 카드 그룹 컬럼을 채웁니다. 예시 3처럼 안에서 나뉘면 "내부 카드 금액"과 "내부 현금성 금액" 두 컬럼에 간편결제사가 알려 준 대로 담습니다. | 1-4 A의 수단 코드와 맞습니다. 간편결제사별 통계와 내부 수단별 통계(예시 5)를 모두 구할 수 있습니다. 예시 2·3의 현금영수증 대상 금액을 내부 현금성 금액으로 바로 압니다. | 컬럼이 4개 늘어납니다. 간편결제사마다 응답 형식이 달라 내부 수단을 우리 코드로 바꾸는 작업이 필요합니다. |
| B | 간편결제사를 수단 코드 값으로 둡니다(`KAKAOPAY`, `NAVERPAY`, `TOSSPAY` 등). 내부 수단 컬럼은 두지 않습니다. | 컬럼이 없습니다. | 수단 코드에 "수단"과 "회사"가 섞입니다. 예시 2·3의 현금영수증 대상과 환불 경로를 알 수 없습니다. 간편결제사가 하나 늘 때마다 수단 코드도 늘어납니다. |
| C | 수단 코드는 실제 내부 수단(`CARD`, `MONEY` 등)으로 두고, 간편결제사 코드는 "어느 앱을 거쳤나"만 나타냅니다. | 예시 5에서 카드 통계가 바로 나옵니다. | 1-4 A의 `EASY_PAY` 코드를 없애야 하므로 그 결정을 바꿔야 합니다. 예시 3처럼 섞인 결제는 수단 하나로 표현할 수 없습니다. |

**추천: A.**
- 환불 경로와 현금영수증은 내부 수단에 따라, 계약·정산은 간편결제사에 따라 갈립니다. 둘 다 따로 필요합니다.
- 예시 4(삼성페이·애플페이)는 PG가 카드로 돌려주면 `CARD`로 두고, 간편결제사 코드는 PG가 알려 줄 때만 채웁니다. 이 규칙을 컬럼 설명에 적습니다.

**A를 고르면 생기는 것 (이름은 후보)**
- 간편결제사 코드(코드 그룹): `KAKAOPAY`, `NAVERPAY`, `TOSSPAY`, `PAYCO`, `SAMSUNGPAY`, `APPLEPAY` 등
- 내부 결제 수단 코드(코드 그룹): `CARD`, `MONEY`, `POINT`, `ACCOUNT`, `MIXED`
- 내부 카드 금액, 내부 현금성 금액 컬럼
  - CHECK: 두 금액의 합 = 결제 금액
  - 6-2(현금영수증 대상 금액)가 내부 현금성 금액을 읽습니다.
- CHECK 두 가지:
  - 수단이 `EASY_PAY`면 간편결제사 코드와 내부 수단 코드가 NOT NULL
  - 내부 수단이 `CARD`면 카드사 코드가 NOT NULL
